# Reference manifest

This folder holds the bibliography, the citation styles and the documents that set the look of each render. Saved PDFs of cited work go in `literature/` and journal guides beside this file, and neither is committed, because both are copyrighted.

## Files

| File | Use |
|---|---|
| `references.bib` | One entry per cited work, each journal article taken from its CrossRef record |
| `apa.csl` | APA citation style, used until the target journal's own style is read from its guide |
| `elsevier-harvard.csl` | Elsevier Harvard citation style, held for the journal once its guide confirms it |
| `style-formal.docx` | Word reference document for the manuscript |
| `style-letter.docx` | Word reference document for the title page and cover letter |
| `style.scss` | Stylesheet for the HTML render |

## Saved sources

Each saved PDF takes one row, naming the file, the work it is, where it came from, the date it was saved and whether it is peer reviewed.
